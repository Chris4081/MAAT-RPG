# Die fünf älteren Projektillustrationen / Five earlier project illustrations

Christof Krieg bestätigte am 20. September 2026, dass alle fünf hier gezeigten
Illustrationen vom KI-Assistenten im damaligen Projektworkflow erstellt wurden.
Diese Herkunftsbestätigung ist für die unten benannten Dateien dokumentiert; sie
werden nicht länger als ungeklärte Quellen geführt. Eine konkrete Bildmodell-Version
wird nicht behauptet.

On September 20, 2026, Christof Krieg confirmed that all five illustrations shown
here were created by the AI assistant during the earlier project workflow. This
owner confirmation records the origin of the named files; they are no longer
listed as unresolved sources. No specific image-model revision is claimed.
