# License text supplement / Ergänzende Lizenztexte

These are unmodified upstream license and copyright texts. `SOURCES.json` records
their source, retrieval/copy date and SHA-256. They supplement the notices retained
inside the installed runtime; they do not replace component-specific notices.

Qt/PySide/Shiboken 6.8.3 advertise alternative licenses in their package metadata.
Module-specific applicability still has to be checked. LGPLv3 incorporates GPLv3,
so both full texts are provided. FFmpeg's LGPLv2.1 text is included separately;
the exact bundled configuration and corresponding sources must still be established.
CPython and llama.cpp-related existing copyright notices are also copied here.

No commercial Qt license is claimed. No new license is granted to project music
or artwork by this folder. This collection is not a complete corresponding-source
distribution or a written source offer. See `THIRD-PARTY.md` and
`SOFTWARE_LICENSES.md` in the packaged documentation for component details.

Deutsch: Unveränderte Lizenztexte mit Quellen und Prüfsummen. Die Sammlung behebt
fehlende Standardtexte, erklärt das Paket aber nicht pauschal für lizenzrechtlich
vollständig. Modulspezifische Hinweise, Quellcode und Build-Informationen sind
zusätzlich erforderlich, soweit die jeweilige Lizenz sie verlangt.
