# MAAT RPG · Linux

Run **`bash setup.sh`** in this extracted folder, without sudo. Setup installs
the required components and starts the game. Later, use **`bash "Start Linux.sh"`**
or **MAAT RPG** in your applications menu.

Starte **`bash setup.sh`** im entpackten Ordner, ohne sudo. Die Einrichtung
installiert die benötigten Komponenten und startet das Spiel. Später verwendest
du **`bash "Start Linux.sh"`** oder **MAAT RPG** im Anwendungsmenü.

Instructions / Anleitungen: `SETUP.md` and `docs/INSTALL_LINUX.md`.
