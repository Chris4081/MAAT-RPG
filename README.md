# 🌿 MAAT-RPG ALPHA
**A narrative AI-RPG powered by ethical intelligence**

MAAT-RPG ist ein lokal laufendes, story-getriebenes Rollenspiel, das KI, Ethik und symbolische Entwicklung verbindet.  
Im Zentrum stehen die fünf MAAT-Prinzipien:

**Harmonie · Balance · Schöpfungskraft · Verbundenheit · Respekt**

> Kein Cloud-Zwang  
> Keine Accounts  
> Alles läuft **lokal auf deinem Mac**

---

## ✨ Features

- 🧠 **Lokale KI** (llama.cpp / Apple MLX)
- ⚔️ **Vollständiges RPG-Kampfsystem** (Normal / Boss / Final)
- 🧭 **Dungeons, Quests, Achievements & Level-System**
- 🎶 **Dynamische Kampfmusik & Cinematic Events**
- 🧩 **Modulares Plugin-System** (Memory, Wiki, Emotion, MAAT-Analyse)
- 🛡️ **Automatisches Kontext-Management** (kein Context Overflow)
- 🔌 **MAAT-OS Architektur** – klar getrennt, erweiterbar, lokal-first

---

## 🔐 macOS Sicherheit (Gatekeeper)

Beim ersten Start kann macOS eine Warnung anzeigen, da MAAT-RPG lokal & unsigniert ist.

Falls nötig:
1. Rechtsklick auf **MAAT-RPG.app**
2. „Öffnen“ wählen
3. Sicherheitsdialog bestätigen

MAAT-RPG benötigt lediglich **Terminal-Zugriff**, um lokal zu starten.
